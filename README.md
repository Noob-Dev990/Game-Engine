# Game-Engine
A simple Raycasting engine - currently in very early development.

**Features** - 640x480 pixel buffer rendering, controllable player, debug menu

**Requirements** - JDK 8 or higher (JRE will NOT work)

**How to launch (for Windows users)** - Put the files on your Desktop and type the following in cmd-  1)  cd Desktop   2) javac *.java   3)   java Core     *OR*  Use the attached .bat file (AutoMan.bat) [ Put the file in the same folder where you put .class files ]

**Controls** - **WASD** = Move the dot  **F3** = Show/Hide Debug screen (currently only shows FPS)
